# Contributing Guidelines

Se aceptan todas las contribuciones, informes de errores, correcciones de errores, mejoras en la documentación, mejoras y ideas.

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your change.
3. Make your updates.
4. Commit your changes with a clear commit message.
5. Push your branch to GitHub.
6. Open a pull request explaining your contribution.

## Reporting Bugs

When reporting a bug, please include a clear description of the issue, steps to reproduce it, expected behavior, and actual behavior.

## Suggesting Enhancements

Enhancement ideas are welcome. Please describe the improvement clearly and explain why it would be useful.
